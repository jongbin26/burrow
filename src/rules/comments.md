# 주석

## 판정

- 그 파일만 읽고 알 수 있으면 삭제 — 파일 밖 사실만 남긴다
- 남길 것: 비직관적 트레이드오프, 우회한 버그(이슈 번호), 외부 제약
- 과거 구현·수정 이력·TODO 나열 금지 — 커밋 메시지의 몫

## 형식

- 불릿 한 줄씩, 마침표 없이 명사로 끊기
- `제거함`·`제거됨` ❌ / `제거` ⭕
- 한 주제 세 줄 이내, 넘으면 커밋 메시지나 PR로
- 주변 주석 스타일을 따라가지 않는다

```ts
// 의존성은 판정 결과 문자열 키로 좁힘   ❌ 코드 재진술
// resolve() 는 매 렌더 새 객체 반환      ⭕ 파일 밖 사실
```

예외: 공개 API docstring, 라이선스 헤더
