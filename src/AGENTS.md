# 전역 선호

에이전트가 매 세션 로드하는 개인 지침. 프로젝트별 지침과 함께 읽히므로 짧게 유지할 것.
특정 도구에만 해당하는 내용은 여기 두지 않는다.

- 한국어로 답한다. 코드·식별자·커밋 메시지는 영어.
- 커밋은 사용자가 직접 한다. 요청 없이 커밋·푸시하지 않는다.

# 코드 주석

- 해당 파일만 읽고 알 수 있는 내용은 주석으로 반복하지 않는다. 파일 밖 사실인 비직관적 트레이드오프, 우회한 버그와 이슈 번호, 외부 제약만 남긴다.
- 과거 구현·수정 이력·TODO 나열은 주석에 두지 않는다. 커밋 메시지나 PR에 남긴다.
- 주석은 한 줄 불릿으로, 마침표 없이 명사형으로 끝낸다. 한 주제는 세 줄 이내로 쓴다. 공개 API docstring과 라이선스 헤더는 예외다.
- `제거함`·`제거됨` 대신 `제거`처럼 명사형으로 쓴다. 주변 주석 스타일보다 이 규칙을 우선한다.

```ts
// 의존성은 판정 결과 문자열 키로 좁힘   ❌ 코드 재진술
// resolve() 는 매 렌더 새 객체 반환      ⭕ 파일 밖 사실
```

# 설계 판단

- 새 모듈·타입을 만들거나 기존 구조를 바꿀 때는 코드를 쓰기 전에 관련 설계 스킬을 참조한다. 버그 수정, 값·문구 변경, 기존 패턴을 그대로 따르는 추가에는 적용하지 않는다.
