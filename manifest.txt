# 홈 디렉토리로 링크할 항목. 출처는 전부 `src/` 아래에 있다.
#   `출처` 또는 `출처 -> 목적지` 형식
#   출처   = 이 레포 기준 상대 경로
#   목적지 = $HOME 기준 상대 경로. 생략하면 .claude/<출처의 파일명>
# 여기 없는 것은 건드리지 않는다.
#
# 출처가 `/*`로 끝나면 그 디렉토리의 자식을 하나씩 목적지 아래로 링크한다.
# 목적지 디렉토리는 실디렉토리로 유지되어, 플러그인·인스톨러가 만든 이웃을 건드리지 않는다.
#
# 목적지의 부모 디렉토리(도구 홈)가 없으면 해당 도구 미설치로 보고 건너뛴다.

# 전역 지침 — 한 파일을 여러 에이전트가 각자의 이름으로 읽는다
src/AGENTS.md -> .claude/CLAUDE.md
src/AGENTS.md -> .codex/AGENTS.md
src/AGENTS.md -> .gemini/GEMINI.md
src/AGENTS.md -> .config/opencode/AGENTS.md

# Claude Code 전용 (settings.json 은 기기별 설정이라 관리하지 않는다)
src/agents/       -> .claude/agents/

# 외부 설치물과 디렉토리를 공유하므로 항목 단위로 링크한다
src/skills/*      -> .claude/skills/
src/skills/*      -> .agents/skills/
